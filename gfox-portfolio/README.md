# Portfolio de Mahdi

Le site React/Vite se trouve dans `gfox-portfolio/`. Les commandes ci-dessous se lancent depuis la racine du dépôt (`Portfolio V2`).

## Démarrer en local

```sh
npm --prefix gfox-portfolio install
npm run dev
```

Garde le terminal ouvert et ouvre l’adresse `Local` affichée par Vite. Le port peut changer si le port habituel est déjà utilisé.

## Vérifications

```sh
npm run build
npm run lint
```

## Pages

- `/` : accueil et présentation
- `/skills` : compétences
- `/projects` : projets
- `/contact` : contact
- `/more` : présentation détaillée
